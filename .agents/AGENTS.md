# Workspace Rules

1. **Verify Builds**: After writing or modifying code, ALWAYS run `yarn build` in the background to ensure everything compiles correctly without TypeScript or ESLint errors. Do not consider a step fully complete until the build passes.
2. **Design Quality**: Make sure every page design is properly aligned, fully responsive, and visually appealing ("wow" factor). Use shadcn/ui components effectively, ensure proper spacing (margins/padding), and use Tailwind CSS for all styling.
